# Animated Lucide compatibility

| Capability | Status |
| --- | --- |
| Native Compose rendering / static fallback | supported |
| Concurrent root scale, rotation, translation and alpha tracks | supported |
| Keyframes, delay, easing, replay | supported |
| Manual, state, visibility and continuous triggers | supported |
| Element transforms and path trim | planned: requires imported element geometry |
| SVG morphing, skew, color/stroke interpolation | not registered until renderer support exists |

The registry truthfully reports a definition's capability state. No icon is advertised as a full Lucide Animated port merely because it can receive a generic motion.
